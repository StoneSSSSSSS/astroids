# Asteroids

A Python arcade game built with Pygame.

## Features

- **4 Asteroid Types** — Standard, Speed (fast), Follow (homing), and Health (requires multiple hits)
- **Power-ups** — Shield, multi-shot, fire rate boost, pierce shot, speed boost, and nuke
- **Boss Fights** — Every 10 levels a boss spawns, tracks the player, and shoots fireballs
- **Escalating Difficulty** — Each level adds more asteroids with tougher variants appearing as you progress
- **Customizable Controls** — Rebind all keys/mouse buttons from the settings menu
- **Persistent Stats** — Tracks highest level, asteroids destroyed, and bosses killed across sessions
